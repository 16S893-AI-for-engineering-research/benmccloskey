02 · Why this course
  • My dissertation work involves building and comparing mixed-integer programming (MIP) and Markov decision process (MDP) formulations for dispatching MEDEVAC assets (helicopters and ground ambulances).
  • Model development and verification is slow and error-prone by hand.
  • This course is where I test whether a coding agent can genuinely accelerate verification work without me losing track of whether the results are correct.
03 · How I use Agentic AI in Dispatching Work today
  • On a MEDEVAC decision-support project with the DAF-MIT AI Accelerator, I use agents around an optimization-based dispatcher so explanations and proposed assignments stay tied to solver evidence.
    • A supervisor agent chooses which evidence layers an explanation needs (patient, dispatch, mission). A separate step writes the brief, and only from layers that were actually opened.
    • Grounding is enforced outside the model. Evidence tools return solver output unchanged, a model’s clarification request is advisory, and skipping the required dispatch layer falls back to a template brief instead of an LLM guess.
    • A separate assigner agent proposes asset-casualty pairings from a feasibility lookup. The same evaluator used to score the plan can then reject it. On hard cases the loop pauses for a human decision rather than committing.
    • Each graph is tested with a fake model at the node boundary. The pipeline decides what evidence to show. I still read the trace and decide whether the explanation is honest.
